# ⚖️ [開源專案] 用 PWA + 本地 LLM 癱瘓違法扣車 SOP

## ⚠️ 系統漏洞與痛點 (The Bug)
現行《道交條例》存在嚴重違憲的執行漏洞：警察僅憑高偽陽性（如感冒藥干擾）的快篩試劑，即可合法扣押民眾車輛。待數月後尿液精密檢驗為陰性（不起訴），無辜民眾卻必須自行負擔數萬元的保管費與代步損失。國家用極低的成本發動錯誤執法，卻讓人民承擔高昂的自證清白成本。

## 💡 我們的解法 (The Patch)
我們正在建構一套非對稱的自動化法律反擊系統（PWA + 本地 LLM）。
民眾只需用手機拍下「不起訴處分書」，系統便會在 30 秒內透過 OCR 與結構化萃取，自動生成針對該分局的「行政訴訟狀、訴願書、國賠請求狀、督察室檢舉信」。
目標：將民眾寫訴狀的門檻降至 0，將海量的行政訴訟與督察檢舉反向倒灌回警政系統，用龐大的行政處理成本逼迫內政部修改這種「先扣車再說」的無理 SOP。
